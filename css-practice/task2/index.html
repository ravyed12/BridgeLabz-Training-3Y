CSS Units

CSS units are used to specify the size of elements in a web page. There are several types of CSS units, including absolute units (like px, pt, in, cm, mm) and relative units (like em, rem, %, vw, vh). Absolute units are fixed and do not change based on other elements or screen size, while relative units adjust based on the context in which they are used.
